# 代码风格

> capsule 视角：业务 capsule 也必须遵守同一套 no_std/unsafe/错误处理规则；
> 它的 crate 头至少包含 `#![no_std]`、`#![forbid(unsafe_code)]`，且不得依赖
> `board-support`/`firmware`/RTIC。目标形态见 [ADR-0008](../adr/0008-静态capsule化内核.md)。
>
> 本文只写**能被门禁执行**的规矩，以及那几条"机械判不了、只能靠评审"的约定。
> 依据与细节在 [`AGENTS.md`](../../AGENTS.md) 的铁律一节。

## 1. 可执行的规矩（`cargo xtask check-style`）

| 规矩 | 为什么 | 怎么判 |
|---|---|---|
| 代码里**不得出现** `todo!()` / `unimplemented!()`（注释/字符串里作为反例提及可以） | `no_std` 固件里一个 `todo!()` 等于**ISR 里静默挂死**；未实现必须是"可观测的运行时事实"（留 `GAP(Px)` + 返回明确错误变体 `NotImplemented`/`Rejected`） | 逐行扫描（去掉注释与字符串字面量后匹配） |
| 每个 crate 的 `lib.rs` **必须以 `//!` 模块文档开头** | 接手者第一眼看的就是它；没有它就得读代码猜 | 检查文件首行 |
| 根 `Cargo.toml` 的 lint 里必须仍有 `missing_docs` 与 `unsafe_code` | **放宽 lint 等于悄悄降低标准**，这类改动必须被看见 | 字符串检查（改动会强制走一次评审） |

## 2. 语言与命名

| 项 | 约定 |
|---|---|
| 注释 / 文档 / 提交信息 / 错误信息 | **一律中文** |
| 标识符（类型、函数、常量、字段、crate 名） | **ASCII**（`snake_case` / `UpperCamelCase`，跟随 Rust 惯例） |
| **测试函数名** | **允许中文**。本仓库全中文，`cargo test` 的输出是给人看的；强行改成英文只会制造噪音与翻译分歧。（这是唯一的例外，且与"标识符 ASCII"并不冲突：测试名不是对外 API） |
| 日志 / 串口输出 / 命令 / 路径 | 保持原文（不要为了"全中文"去翻译设备名与命令） |

## 3. 机械判不了、靠评审的三条

1. **注释解释"为什么"，而不是"做了什么"**。`// 自增计数器` 是噪音；`// 这里必须减一：器件手册的字段是"周期数 − 1"` 才是信息。
2. **每个非常规决定都要有依据**：优先引用**本机可查的证据**（本板既有 C 固件、数据手册、`docs/`），而不是"我记得"。
3. **不写"看起来完成"的代码**：未实现就留缺口标记；不确定的硬件事实标 `🟡`，且**不得当作事实使用**。

## 4. 错误处理与类型

| 规矩 | 做法 |
|---|---|
| 不用 `unwrap()` / `expect()` / `panic!` 表达"不可能发生" | 纯逻辑 crate 由 lint 直接拒绝；真"不可能"用类型表达（newtype / 枚举） |
| 自研驱动必须落在 BSP 且计入 unsafe 预算 | 见 [`ADR-0005`](../adr/0005-自研flexcan驱动落在bsp.md)：`flexcan`/`flexspi_ip` 走"基址 + 照抄偏移"的直访路线，偏移必须写清出处（`[RM …]` / CMSIS 头） |
| 未确认的外部接口不做兜底默认值 | 见 [`ADR-0007`](../adr/0007-未知协议做成类型.md)：未知必须隔离成没有默认值的类型；填一个"看起来合理"的值等于把错误扩散到测试与文档 |
| 掉电原子性写在**策略**里而不是注释里 | 见 [`ports::double_bank`](../../crates/ports/src/double_bank.rs) 与 [`filesystem`](../../crates/filesystem/src/lib.rs) |

## 5. 提交前自检

```bash
cargo xtask verify      # 全量门禁（唯一验收口径）
cargo xtask coverage    # 覆盖率（阈值 90%）
cargo xtask context     # 机器可读的项目上下文（Agent/脚本用）
```
