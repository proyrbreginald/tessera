# ADR-0006：测试分层与"仿真优先"

## 状态

已采纳（决策）

## 决策

七层测试体系：编译期 / 单元 / 属性 / **负例** / 场景 / 产物 / HIL。
**主机场景仿真是一等公民**；掉电原子性拆成"可穷举的策略 + 薄介质"。

## 理由

Boot ROM、FCB 握手、外部 Flash 时序与真实中断延迟无法在主机上复现，
而 i.MX RT1021 在 QEMU/Renode 中支持并不完整。如果不主动压缩这道鸿沟，
就会退化成"一个破坏启动流程的改动要等到夜间 HIL 才发现"。

目标：**让"必须靠真机才能发现的问题"只剩电气与真实时序两类。**

## 设计阶段的实际收益（不是理论）

把 `Store::write_atomic` 的掉电原子性拆成：

```text
DoubleBankStore（双份+序号+CRC 的策略）  ← 纯逻辑，主机可**穷举每个掉电字节位置**
        │
RawMedium（读/擦/写三个动作）            ← 唯一不可测的部分，已被压到最薄
```

穷举测试立刻抓到一个真实缺陷：早期实现"先按序号挑出最新的、再校验它"，
于是一旦最新那份是半写状态，读路径会报错并**丢掉仍然完好的旧值**。

## 后果

- **正面**：难以验证的契约（掉电原子性）变成了可在 CI 里穷举的纯逻辑。
- **代价**：需要维护主机替身（`simulator`）与场景脚本；替身本身也必须
  `forbid(unsafe_code)` —— 如果替身有 UB，主机测试的绿灯毫无意义。
- **诚实边界**（2026-10-16 更新）：HIL 层**已接线**并多次上机（[`板级事实`](../03-硬件/板级事实.md) §6
  有 2026-10-09 起的多次记录：FCB 启动、控制台、PIT 64 位链式时基、SDRAM 全片自检、
  MPU + I/D cache、文件系统只读挂载、栈余量实测、DMA 池非缓存自证）。主机测试
  **474 个用例**（2026-10-16 复测；数量会变，当前值以 `cargo xtask test-host` 为准）。
  仍**没有**闭合真机证据的是：总线对端的电气与真实时序、掉电原子性（介质侧）、
  看门狗（未启用）、A/B 升级（未实现）。
