# 业务接入

> 平台只提供底座：业务 crate 建在**仓库之外**，通过 capsule SDK/端口契约接入，
> 用主机仿真器完整重放。仓库内不包含任何业务语义。

## 1. 接入骨架

```rust
use sdk::prelude::*;

pub struct MyCapsule { /* 状态 */ }

impl<C> Capsule<C> for MyCapsule {
    fn name(&self) -> &'static str { "my-capsule" }
    fn phase(&self) -> Phase { Phase::Business }
    fn init(&mut self, _ctx: &mut C) -> Result<(), InitError> { Ok(()) }
    fn step(&mut self, _ctx: &mut C) -> CapsuleStep { CapsuleStep::Idle }
}
```

- 组合：业务 crate 在仓库外建立自己的 `Product`，把 capsule 注册进固定容量的 `CapsuleSet`；
- 依赖边界：业务 crate 依赖 `sdk`/`ports`，**不得**依赖 `board-support`/`firmware`/`rtic`/`imxrt-*`；
- 主机测试：用 `simulator` 的 `MockBus`/`ManualClock`/`MemMedium`/`CapturingLog` 重放。

## 2. 端口契约

| 端口 | 用途 |
|---|---|
| `ports::Bus` | 半双工/全双工总线收发（Modbus-RTU 等） |
| `ports::Clock` | 可注入时间源（主机测试不读硬件） |
| `ports::Store` | 持久化存储（文件系统之上） |
| `ports::LogSink` | 日志输出 |
| `ports::RawMedium` | 原始介质访问边界 |

## 3. 当前能力边界（先读再设计）

- `sdk::Capsule` 的 `on_event` 事件分发**未实现**；S2 上下文能力对象化、S3 基础 capsule
  外提与仓库外插件门禁也未实现（见 [安全与约束](安全与约束.md)）。当前业务 capsule 只能写
  无能力的 `impl<C> Capsule<C>`。
- capsule 是**编译期静态组合**，不是运行期热替换；safe capsule 也不是安全隔离。
