# 构建与验证（仓库怎么用）

> **所有入口统一为 cargo / `cargo xtask`**：仓库没有 Makefile，也不使用 make。
> 唯一验收口径：`cargo xtask verify`。台架抓包/烧录/自检全部内建在 xtask（Rust）；只需 `cargo xtask setup` 安装 pyocd。

## 1. 环境

| 项 | 说明 |
|---|---|
| Rust | 最新 stable（根 `rust-toolchain.toml`；不锁定补丁版本） |
| 目标 | `thumbv7em-none-eabihf`（默认 target，`cargo build --release` 就是固件） |
| 主机测试 | 显式 `--target x86_64-unknown-linux-gnu`（`cargo xtask test-host` 已处理） |
| 台架 | `cargo xtask setup` 建 `.venv`（pyocd） |
| 探针/串口 | SWD `/dev/pudu-debugger-swd`，串口 `/dev/pudu-debugger-16p-uart`（`PYOCD`/`BASE_SERIAL` 可覆盖） |

## 2. 日常命令（全部）

```bash
cargo xtask verify        # 唯一全量入口：门禁 + fmt/clippy + 主机测试 + 构建 + 产物断言
cargo xtask gates         # 18 项静态门禁逐条 PASS/FAIL
cargo xtask gate <name>   # 单跑一项门禁（名称见 `cargo xtask gates` 输出）
cargo xtask test-host     # 主机测试（纯逻辑层）
cargo xtask coverage      # 主机行覆盖率（阈值 90%）
cargo xtask context       # 机器可读上下文（crate/门禁/缺口/预算/最近测试）
cargo build --release     # 只构建固件 ELF
cargo fmt --all           # 格式化
cargo clean               # 清理构建产物
```

静态门禁名称：`layering` `capsules` `interrupt-priorities` `lint-headers` `unsafe`
`gaps` `fault-handlers` `critical` `api-usage` `style` `docs` `memory`
`code-placement` `image` `size` `flash-map` `compile-fail` `trace`。

## 3. 真机

```bash
cargo xtask setup           # 一次性：建 .venv（pyocd）
cargo xtask flash           # 构建 + 烧录
cargo xtask flash --erase   # 全片擦除 + 烧录（改分区/FS 格式后必须）
cargo xtask reset           # 复位
cargo xtask monitor         # 抓串口并校验时基漂移（±2%）
cargo xtask bytecheck       # 控制台逐字节校验（改时钟/中断/控制台后必跑）
cargo xtask test-target     # 目标端自检 5 项
cargo xtask soak --minutes 5   # 长稳采集（默认 30 分钟）
```

烧录直接由 xtask 调 pyocd 完成（构建 → `pyocd load --format elf`），不经过 shell 脚本。

## 4. Tock 运行时（后续固定采用；当前迁移中）

```bash
cargo xtask tock-build            # 构建 tock/ 下的最小 Tock 镜像
```

## 5. 版本号

- `VERSION` 是唯一真源（`crates/firmware/build.rs` 构建期注入并校验格式）；
- **改固件行为就递增**；只改文档/工具不递增。

## 6. 排障

| 现象 | 处理 |
|---|---|
| 串口 `EBUSY` | 查持有者（`screen`/抓包进程），让用户释放；不要擅杀 |
| 编译通过但板子不启动 | 先 `cargo xtask gate image`；再确认烧录偏移 0 和 FCB |
| 改了分区/FS 格式后异常 | 必须 `cargo xtask flash --erase` 全片擦除 |
| `verify` 红 | 先 `cargo xtask gates` 看哪条失败；单条用 `cargo xtask gate <name>` |
| pyocd 找不到 | `cargo xtask setup`；或设 `PYOCD=/path/to/pyocd` |
