# 分层与依赖规则

> 这张表由 `cargo xtask gate docs` **双向核对**：少一个 crate 报"缺行"，多一个报"陈旧"。
> 规则本身由 `cargo xtask gate layering` 在依赖闭包上执行（含 `dev-dependencies`）。

| `ports` | 纯逻辑 | `Bus`/`Clock`/`Store`/`LogSink`/`RawMedium` 端口契约 | 无硬件 |
| `simulator` | 纯逻辑 | 主机替身：脚本化总线、手动时钟、可注入掉电介质 | `ports` |
| `sdk` | 纯逻辑 | capsule SDK 稳定门面：`Capsule`/`CapsuleSet`/`Product` | 无硬件 |
| `product` | 纯逻辑 | 默认产品组合根：`Platform` 注入契约与六个服务槽 | `sdk` |

## 2. 规则

1. **纯逻辑 = 可主机测试**：不读寄存器、时间可注入、I/O 走端口；`forbid(unsafe_code)` +
   统一 lint 头（`cargo xtask gate lint-headers`）。
2. **硬件访问只允许在 `board-support`**：其余 crate 直接依赖 `imxrt-*`/`cortex-m*`/`rtic`
   会被 `check-layering` 拒绝；`firmware` 只做平台接线与 RTIC 任务。
3. **插件边界**：依赖 `sdk` 的 crate 不得直接依赖 `board-support`/`firmware`/`rtic`/`imxrt-*`
   （`check-capsules`，当前只扫仓库内 `crates/`；仓库外业务接入见 [业务接入](../业务接入.md)）。
4. **数字单一来源**：分区表在 `flash-layout`，内存/栈预算在 `memory-layout`，实时预算在
   `primitives::budget`；文档只解释"为什么"，数字由门禁核对。
