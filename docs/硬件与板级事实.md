## 1. MCU 与存储器

| 项 | 值 |
|---|---|
| MCU | `MIMXRT1021CAG4A`，Cortex-M7 @396 MHz，144-LQFP |
| 片上 RAM | 256 KB FlexRAM（默认：ITCM 64 KiB / DTCM 64 KiB / OCRAM 128 KiB） |
| 内部程序 Flash | **无**（型号中的 `4` 是主频位，不是 SIP Flash） |
| 外部程序 Flash | Winbond `W25Q256JVEQ` 32 MiB，3 V，quad-SPI |
| 外部 SDRAM | `W9825G6KH-6I` 32 MiB @ `0x8000_0000`，SEMC CS0 @62.5 MHz（全片自检通过） |
| 晶振 | `Y1` 24 MHz，负载电容 11 pF |
| 控制台 | LPUART1 115200 8N1，节点 `/dev/pudu-debugger-16p-uart` |
| SWD | `/dev/pudu-debugger-swd`（SWDIO/SWCLK 在 J7） |

## 2. 引脚（本固件使用）

| 功能 | 焊盘 | ALT | 说明 |
|---|---|---|---|
| UART1_TXD | `GPIO_AD_B0_06` | 2 | 22R → J7 pin11 |
| UART1_RXD | `GPIO_AD_B0_07` | 2 | 22R → J7 pin12 |
| FlexSPI1-A | `GPIO_SD_B1_11/07/08/10/09/06` | 1 | CS/CLK/DATA0..3 接 U2 |
| CAN2_TX | `GPIO_AD_B1_00` | 2 | → TJA1044T TXD |
| CAN2_RX | `GPIO_AD_B1_01` | 2（daisy=3） | ← TJA1044T RXD |
| SWDIO/SWCLK | `GPIO_AD_B0_00/01` | — | J7 调试口 |

CAN 的 ALT 与 RX daisy 依据官方 `fsl_iomuxc.h` 与板级 `pin_mux.c`，**不要猜**；
第一版曾误用 `GPIO_AD_B0_14/15`（ENET 焊盘）已修正。

## 3. 时钟与串口

- 控制台取 **24 MHz 晶振**（`UART_CLK_SEL=1`、`PODF=1` → 115384 Bd，误差 +0.16%），
  不取 PLL3：**不依赖 PLL 是否锁定**，时钟树配错时控制台仍能出字。
- 串口出字只证明波特率与引脚对，不证明时钟树对；时基漂移判据用 `cargo xtask monitor`
  （设备 uptime vs 主机时间，±2%）。
- 启动横幅会回读并打印时钟/PIT/FCB/MPU/栈/DWT/器件 ID —— **报事实，不报意图**。

## 4. 启动头与 FCB

- Flash 偏移 0..8 KiB 是启动头（运行期只读）：FCB 在 0（512 B）、IVT 在 `0x1000`、
  boot data 紧随；应用从 `0x2000` 起（阶段 1 从偏移 0 起的应用会临时占用 `bootloader` 区）。
- 写坏启动头 = Boot ROM 不启动 = 只能 BOOT_MODE 引脚 + 串口下载器救；
  **绝不允许运行期写**。
- 分区与 4 字节寻址纪律见 [Flash 布局与用途划分](02-架构/Flash布局与用途划分.md)。

## 5. 复位、故障与诊断

- 四个故障向量（HardFault/MemManage/BusFault/UsageFault）各自指向真实实现或**刻意升级**，
  `check-fault-handlers` 从链接产物断言，空桩会被抓。
- `fault-decode` 解码复位原因、CFSR/HFSR、入栈帧与跨暖复位崩溃记录；启动横幅打印
  `reset :` / `上次故障:`。
- 调试器读数与固件自报冲突时**以固件自报为准**（曾读到错误的 CPUID）。
- 已知硬件层反常：DWT 会被启动期大范围内存测试清掉，根因未解释；固件按心跳自动重装并计数。

## 6. 已踩过的硬件坑（简）

- FlexSPI 逐字节 `read_volatile` 会把挂载扫描拖到几十秒（像死机），必须批量拷贝；
- 改 FlexSPI 时钟必须同时重算 dummy（`0x06` 只对 100 MHz 正确），否则读到垃圾；
- 4 字节地址若退回 3 字节，越过 16 MiB 的访问会静默别名（可能擦掉启动头）；
- 本板 CP UID/OTP 区域读法见 BSP；未经确认不得批量写熔丝；
- 看门狗（外部 SGM706）驱动源 `WDG_CTR` 未确认，贸然启用只能断电恢复。
